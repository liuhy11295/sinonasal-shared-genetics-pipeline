# 07 MAGMA gene and pathway analysis

- `scripts/prepare_resources.sh`: obtains MAGMA and pathway resources.
- `scripts/merge_ld_reference.sh`: prepares the European PLINK LD reference.
- `scripts/run_pair.py`: runs one disease-pair analysis.
- `scripts/aggregate_results.py`: aggregates genes, pathways, mappings, and FUMA inputs.
